The following are my instructions in how to build and run the project in its current state

Requirements:
 - Visual Studio

1. Locate the shell.bat script in the /misc directory and change the path to be the current path of the misc folder. Ensure that the locations for vcvarsall.bat and the winrt directories are set according to the location on your computer.
2. Open a command terminal and go travel to the /misc directory to run the shell.bat script.
3. Go into the /code directory to run the build.bat script.
4. The new executable will be located in the /build directory which you should now be able to run in Visual Studio.
